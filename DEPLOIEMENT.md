# Déploiement ZEturf

Le projet complet est dans `Tableur_ZEturf_Netlify.zip`. Netlify installe les dépendances décrites à la racine, extrait cette archive dans `app`, exécute ses 18 tests puis publie `app/public` et le relais dans `app/netlify/functions`.

Pour modifier le projet, extraire l’archive et lire `LIRE-MOI.md`. Le fichier `Index.html` historique reste conservé.
